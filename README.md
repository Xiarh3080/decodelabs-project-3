# TaskMaster – Interactive Web Elements (Project 3)

**Frontend Development Internship – DecodeLabs**

---

# 📌 Project Overview

This project was developed as **Project 3** of the **Frontend Development Internship** at **DecodeLabs**.

The objective of this project is to build an **interactive web application** using **HTML5, CSS3, and Vanilla JavaScript**. The project demonstrates JavaScript fundamentals, DOM manipulation, event handling, and dynamic content updates through a responsive Task Manager application.

The application allows users to manage daily tasks, switch between light and dark themes, search tasks, view live statistics, and interact with a contact form.

---

# 🎯 Project Objectives

* Build an interactive webpage using JavaScript.
* Demonstrate DOM Manipulation.
* Implement Event Listeners.
* Dynamically update webpage content.
* Create a responsive user interface.
* Improve user interaction using JavaScript.
